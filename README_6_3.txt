APEX SCALP GOD 6.3 — THESIS TIMING TRAP

Core principle: DIRECTION IS NOT TIMING. A medium-term thesis can ultimately be right and still be unusable as an immediate entry because the adverse excursion can liquidate a small account first.

New in 6.3:
- Thesis Timing Trap / Delayed-Activation Court.
- Tracks current and maximum adverse excursion in ATR from the frozen parent entry.
- Tracks recovery from the worst adverse point.
- Labels PREMATURE THESIS TRAP when the parent signal is materially early.
- Opens a COUNTER WINDOW only when the adverse leg is still active and shock/cascade vetoes are clear.
- Closes the inverse fade when the parent thesis begins activating.
- Parent thesis remains context only; it is never promoted directly into execution.
- Timing state is logged into the autopsy journal for later calibration.
- Existing journal, signal lock, path ledger and microstructure memory are preserved.

Legal/ethical boundary: this build models public market behavior and execution timing. It does not manipulate markets, spoof orders, use stolen/private information, or bypass broker/exchange rules.
