APEX SCALP GOD 7.4.0 — OPPORTUNITY CAPTURE + WHIPSAW GUARD

Purpose
- Show real executable scalp opportunities while forward proof is still building.
- Do NOT convert every directional thesis into an entry.
- Prevent the known failure mode: STRONG SELL/BUY issued after an extended move just before a counter-squeeze, followed later by the original trend.

Key changes
1. Forward proof is a CONFIDENCE tier (EARLY / DEVELOPING / VERIFIED), not an automatic 20-sample padlock. Mature materially negative exact-bucket evidence can still block.
2. Closed-M5 trigger remains usable up to 4 minutes, but only while live price remains inside the anti-chase displacement zone. The displayed ENTER command still expires after 60 seconds.
3. Multi-candle whipsaw guard measures 3/5-bar extension, RSI exhaustion, reversal fitness, rejection wick and the existing counter-first path engine.
4. If a continuation bias is vulnerable to a counter move, APEX says WAIT — COUNTER MOVE RISK. It can re-authorize after a pullback and a fresh resumption candle.
5. Pullback/resumption is explicitly recognized, allowing repeated opportunities inside the same larger trend rather than treating the first missed entry as the only trade.
6. Live MT5 spread can authorize a conservative friction model when manual broker specs were not entered: spread + slippage buffer + commission reserve. Manual broker specs still take priority.
7. Gold already uses USD/JPY + EUR/USD + USD/CHF as a USD-strength cross-market confirmation. 7.4 uses this as a small confidence modifier, never as a guaranteed inverse law.
8. Existing localStorage/IndexedDB learning keys are unchanged.

No software test can guarantee profit or prevent loss. The patch is designed to improve opportunity capture and reduce a specific whipsaw-entry failure mode; it must still be forward-tested.
