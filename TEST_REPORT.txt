LIVE-FEED LIMITATION OF THIS TEST ENVIRONMENT
- The container used for the build cannot reach external calendar endpoints, so live provider connectivity could not be proven here.
- The runtime is deliberately fail-closed: if neither a current feed nor usable stale cache exists, it shows NEWS RISK UNKNOWN and does not permit a fresh ENTER because of an assumed 'clear' calendar.
- First real-world beta test should confirm the deployed browser can fetch the calendar provider and that event times display correctly in the user's local browser time.

IMPORTANT
These tests validate software behavior, memory migration and execution invariants. They do not prove profitability, forecast accuracy, or that any news event will move a market in a particular direction.
