TITAN GOD 8.0 — CONSENSUS ENGINE

Major forensic upgrade over GOD 7.0:
- Final BUY/SELL now requires the consensus/safety gate to PASS.
- If technical direction exists but evidence is conflicted/uncertain, the headline decision becomes WAIT and the bias is shown separately.
- Existing signal locks are invalidated when the consensus gate fails.
- Strong BUY/SELL is only allowed with stronger cross-layer agreement and lower uncertainty.
- Confidence is penalized by uncertainty, conflict, rejected historical evidence, and degraded news connectivity.
- News feed failure is explicitly labelled NEWS FEED DEGRADED and is never treated as “no news”.
- BEST NOW leader uses the same consensus gate as the main World Brain.
- Autopsy journal now stores bias + consensus reason + uncertainty/conflict/news-feed health.
- PWA cache/version bumped so an installed iPhone app can receive the new build.

This build remains a decision-support prototype. It does not guarantee future market direction or profit.
